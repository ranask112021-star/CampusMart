# CampusMart

CampusMart is a React/Vite marketplace client and Express/MongoDB API. In production, the Express server serves the built frontend and API from one public URL.

## Run locally

Use two terminals:

```powershell
cd server
npm install
npm run dev
```

```powershell
cd client
npm install
npm run dev
```

The local Vite server proxies `/api` requests to `http://localhost:5000`. Configure MongoDB and Cloudinary in `server/.env` using `server/.env.example`. The client is available at the URL printed by Vite, usually `http://localhost:5173`.

## Deploy a public demo on Render

The repository includes a Render Blueprint in `render.yaml`. It builds the client and runs the API in one web service, so visitors use a single URL and can register/login from their own devices.

1. Push this repository to GitHub. Do not commit `server/.env` or paste secret values into the repository.
2. Create a MongoDB Atlas database and a Cloudinary account. The API needs the MongoDB URI for sign-up/login and the Cloudinary credentials to accept photo uploads.
3. In Render, choose **New + → Blueprint**, connect the GitHub repository, and deploy `render.yaml`.
4. Enter the requested `MONGO_URI` and Cloudinary environment values in Render. The Blueprint generates `JWT_SECRET` securely.
5. In MongoDB Atlas, allow the Render service to connect. For a public demo, a broad IP allow rule may be convenient but reduces database network protection; prefer the narrowest network access practical and use a dedicated database user with a strong password.
6. Wait for `/api/health` to pass, then open the Render URL and register a test user. Share that public URL with the person testing the app.

Render's free web service may sleep when idle and take a short time to wake up. This project currently uses Cash on Delivery only; no online payment is collected. Password reset is disabled in production until an email provider is configured. Local sample listings are for display/demo only and are not real inventory.

## Environment variables

Set these in the Render service dashboard, not in source code:

- `MONGO_URI` - MongoDB connection string.
- `JWT_SECRET` - generated by the Render Blueprint.
- `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET` - image uploads.
- `NODE_ENV=production` - production behavior.
